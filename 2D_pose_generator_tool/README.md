## 2D姿势生成器工具

### 由于我的模型是需要2D姿势和图片的输入才可以得到输出

* 具体生成网络可以利用 `HRNet` 或者 `OpenPose` 网络进行推理得到结果。**(可惜我没有实现，希望你们可以实现)**
* 写了手动标注2D姿势的界面软件，需要` 手动标注`。 **这个界面有点丑，但是可以用。**
* 所以这里是生成工具，将调试好。**提供给未来想做我这个方向的师弟们。**

`说明` 方法不唯一，你也可以不利用2D关键点信息，需要自己改一下网络。可以将网络改成单输入成图片，自己训练。(需要自己看论文，看别人是怎么做的)

`源码_1` [HRNet](https://github.com/HRNet/HigherHRNet-Human-Pose-Estimation)

`源码_2` [OpenPose](https://github.com/tensorboy/pytorch_Realtime_Multi-Person_Pose_Estimation)

`关键点标注生成器使用说明` 
* 运行 `main_test` 文件，出现界面之后。点击 `打开文件` 选项(右下角)，选择存放图片的文件夹 `images` 打开，然后点击 `PreImage`
  选项，就会出现图片。
* 用鼠标点击即可。所有的操作界面上都会有 `提示`。

`备注` 这个生成器的结果自动保存为 `JSON` 文件。但是内容需要修改，具体的修改一定要参考 `demo/input` 文件夹下的 `2d_pose_result.json` 文件。
**(我是手动改成它的格式的)**，你们也可以看懂代码之后改一改。
